# Start Here

New to AI and machine learning? Begin with this short module before Module 1. It explains what the field is and how its parts fit together, with small programs you can run in your browser:

- what AI, machine learning, deep learning and generative AI each mean, and a short history
- the difference between writing rules and learning from examples
- what "learning" actually is: parameters, a loss, and gradient descent
- the kinds of machine learning: supervised, unsupervised, reinforcement and self-supervised
- overfitting, and why models are always tested on data they haven't seen
- how neural networks and large language models like ChatGPT work, built up from a tiny next-word generator
- what AI can't do, and why that matters when you build it
- how a real ML project runs, and which module teaches each step

No programming or maths is needed. If some code looks unfamiliar, run it, read the output, and come back to it after Module 1.
